# wayline
Wayline is an editorial luxury travel-planning web application built with React, Tailwind CSS, and Framer Motion, designed to curate bespoke itineraries across ten iconic Indian destinations: Delhi, Jaipur, Hyderabad, Bengaluru, Mumbai, Chennai, Kerala, Pune, Manipur, and Andaman. The experience opens with an animated splash screen featuring a rotating compass emblem and a floating pill navigation bar for seamless switching between Location, Plan, and Payment views. Destinations are showcased in a uniform 5×2 architectural arch grid with hover dimming, zoom animations, and taglines. Selecting a city launches a four-step trip planner featuring smart origin auto-suggestions that recognize both official names and historical aliases like Bangalore, Bombay, Madras, and Kochi, alongside dual calendar pickers with live night calculation, guest and room steppers, and a group-aware budget advisor that recommends spending targets with a one-tap apply button and tiered travel expectations. Curated packages dynamically adjust pricing to match trip parameters, highlight within-budget options, and incorporate regional culinary photography. Selecting a package opens a full-screen split itinerary with scroll-animated path tracing, leading to a transparent payment breakdown with an eight percent contingency buffer and zero-markup direct provider booking links.
